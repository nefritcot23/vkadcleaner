# VK Ad Cleaner 1.1.3

## Установка / обновление
1. Распакуйте архив в отдельную папку.
2. Откройте `chrome://extensions` и включите «Режим разработчика».
3. Если установлена предыдущая версия из другой папки — удалите её, затем нажмите «Загрузить распакованное расширение» и выберите папку `VK-Ad-Cleaner`.
4. Перезагрузите вкладку ВКонтакте. Поддерживаются адреса vk.ru и vk.com.

## Обучение
На карточках ленты появится панель «Помоги фильтру»:
- **Это реклама** — сохраняет положительный пример и скрывает публикацию.
- **Обычный пост** — сохраняет отрицательный пример.

Примеры сохраняются локально через `chrome.storage.local`; никакие данные никуда не отправляются. После накопления минимум двух примеров каждого типа расширение начнёт автоматически скрывать только очень похожие на рекламные примеры публикации. Порог намеренно консервативный, чтобы не прятать обычные посты. Это лёгкий локальный классификатор по тексту, ссылкам, доменам и структуре карточки, а не нейросеть.

В окне расширения отображается число примеров; там же можно отключить автоматическое обучение или очистить его. Правило доменов работает независимо от обучения.

## Ограничения
Классификатор зависит от того, какие элементы ВК доступны в DOM. Если панель разметки не появилась на конкретной карточке, пришлите скриншот — потребуется добавить её фактический контейнер в селекторы. Автоматическое распознавание пока экспериментальное; проверяйте первые результаты и исправляйте ошибки отметками.


В версии 1.1.3 панель обучения размещается внизу соответствующей публикации. Её показ можно отключить в настройках расширения («Показывать кнопки обучения в ленте»). Автораспознавание рекламы и показ обучающих кнопок управляются независимо.
